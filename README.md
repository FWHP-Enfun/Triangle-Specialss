# 三角特刊體 Triangle Specialss
https://www.maoken.com/zhengyi/10419.html

因為逐浪萌芽字的英文字形是用商業字體，我所以想改一些，換成Merienda這個SIL開源字體，不過我有修改一些，用簡單方式去改，中英之間還是風格不同

Since the English typeface used in ZoomlaMengyas is a commercial font, I decided to make some changes and replace it with Merienda—an open-source font licensed under the SIL Open Font License. I’ve made a few simple modifications, though the styles of the Chinese and English characters still differ.

反正古老的中文字體不用心設計英文字體，這個字體很難改，我只改「乘」

In any case, the English-language characters in these old Chinese fonts weren't designed with much care, and they are very difficult to modify—so I’m only changing the character "乘"

跟偏歪的黑趣體一樣，不加繁體，只用簡單方式修改

Similar to the slanted "black-fun" (hei-qu) typeface, this version does not include traditional Chinese characters and uses only simple modifications.
